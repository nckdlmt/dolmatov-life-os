# Dolmatov Life OS

Персональная система дел, целей и базы знаний.

## Хранение

- Локальный режим сохраняет данные в браузере.
- Облачный режим использует Supabase PostgreSQL и автоматически переносит существующий локальный снимок при первом входе владельца.
- Схема базы хранится в `supabase/migrations`.

## Локальный запуск

Откройте папку через локальный HTTP-сервер. Пока `cloud-config.js` не заполнен, приложение работает полностью локально.

## Обновление зависимостей

```sh
npm install
npm run build:vendor
npm run check
```

Собранный клиент Supabase хранится локально в `vendor/supabase.js`, поэтому приложение не зависит от внешнего CDN во время работы.
